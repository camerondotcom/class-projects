# Class Projects

A collection of Python projects I built for coursework.

## Projects

- **CSV Parser**: Reads a CSV file and prints a summary of its contents.
- **Web Scraper**: Fetches a webpage and extracts headline text.

## How to Run

### CSV Parser
1. Install Python if you do not have it.
2. Run: `python csv_parser/csv_parser.py data.csv`

### Web Scraper
1. Install the required libraries: `pip install requests beautifulsoup4`
2. Run: `python web_scraper/web_scraper.py`
